# Example SAXS dataset (not measured at CoSAXS)

`Cluster_growth_9_1079background_subtracted.dat` – background-subtracted SAXS data (q in Å⁻¹, intensity in a.u.)
from a study of bismuth-oxido cluster growth, published in *Angew. Chem. Int. Ed.* 2021, e202103641
(https://doi.org/10.1002/anie.202103641).

The file and the candidate cluster structures (`bi_cluster_structures.json`) were taken from the teaching app
`saxs_analysis` in the course repository
https://github.com/AndySAnker/2026_Applications-of-X-ray-and-Neutron-Scattering-in-Biology-Chemistry-and-Physics

In the game they are shown in the CoSAXS analysis tab as an *example of the kind of data and analysis* possible at a
SAXS/WAXS beamline. They were **not** recorded at MAX IV / CoSAXS.
